# Projecte: Restaurant Els Coberts 🍽️

Aquest projecte consisteix en el disseny i desenvolupament d'una pàgina web corporativa per a un restaurant, creada com a activitat pràctica per posar en joc competències de maquetació, disseny adaptatiu i integració de contingut multimèdia.

## 🚀 Resum del Projecte

La web **"Els Coberts"** és una pàgina que inclou seccions de presentació, carta de menús (utilitzant CSS Grid), una galeria d'imatges interactiva, un formulari de reserves i un apartat de vídeo amb controls personalitzats. El projecte s'ha dividit en tres fases evolutives:

### 1. HTML / CSS (Fonaments)
**Objectius principals:**
* **Estructuració semàntica:** Reconeixer les possibilitats de modificar les etiquetes HTML per definir l'esquelet del lloc.
* **Estils externs:** Definir i associar estils globals a fulls externs per mantenir un codi net.
* **Personalització:** Identificar les diferents propietats de cada element i crear classes d'estils específiques.

### 2. HTML / CSS / Responsive
**Objectius principals:**
* **Adaptabilitat:** Redefinir estils per adaptar el contingut a diferents mides de pantalla.
* **Layouts avançats:** Implementació de dissenys flexibles i graelles que s'ajusten segons el dispositiu.
* **Consolidació:** Aplicar de nou els principis de classes d'estils i validació en entorns multidispositiu.

### 3. Transicions, Animacions i Vídeos
**Objectius principals:**
* **Contingut Multimèdia:** Reconèixer les tecnologies per incloure vídeo i configurar els navegadors per suportar-lo correctament.
* **Interactivitat:** Afegir elements interactius i multimèdia als documents web per millorar l'experiència de l'usuari.
* **Dinamisme:** Aplicar transicions i animacions per fer la navegació més fluida.

**On vaig posar les animacions?**
* Text a la capçalera que vagi apareixent poc a poc al carregar la pàgina per primera vegada
* Botóns del menu navegació, amb el hover, el text creixi i canvia de color
* Botó reservar, amb el hover, creixi
* Imatges de la galeria, amb el hover, canvia el color i fan una volta
* Elements de la barra de navegació que es mouen d'esquerra a dreta en 4 frames

---

## 🛠️ Tecnologies utilitzades
* **HTML5:** Estructuració semàntica i formulari de reserves.
* **CSS3:** Ús de variables, Flexbox, CSS Grid, Media Queries i animacions `@keyframes`.
* **JavaScript:** Control de vídeo (play, pause, mute) i canvis d'estil dinàmics en fer scroll.

## 📁 Estructura del codi
* `index.html`: Estructura i scripts de control.
* `style.css`: Estils generals, grid de la carta i animacions.
* `styleHeaderFooter.css`: Estils específics per el manu navegació i el peu de pàgina.
